# Prompt para Gemini AI Studio / Emergent AI

Crie uma aplicação web React/Vite chamada NEXUS AI COMMAND CENTER, com interface futurista, dark theme, estilo dashboard holográfico enterprise. A aplicação deve reproduzir visualmente uma plataforma de agente conversacional multitarefa com:

- Header superior com status do sistema, temperatura do núcleo IA, rede, segurança e modelo ativo.
- Sidebar esquerda com rede de agentes: NEXUS CORE, ARCHITECT AI, STRATEGY AI, DATA SYNAPSE, THREAT SENTINEL, FLOW COMMAND, VOICE INTERFACE e DOC INTELLIGENCE.
- Centro da interface com uma esfera de plasma radioativo no meio, brilhante, viva, com arcos elétricos, anéis concêntricos, partículas, ondas de frequência e status “SPEAKING”.
- Área de comando conversacional com waveform de voz, input de comando, botão de microfone e botão de envio.
- Painel direito com memória/contexto, atividade recente, fila de tarefas, nível de confiança e fontes/citações.
- Cards inferiores com automações, performance, documentos recentes, relatórios gerados e workflows ativos.

Requisitos técnicos:
- React + Vite.
- CSS puro avançado, sem Tailwind obrigatório.
- Usar animações CSS para plasma, ondas de áudio, faíscas e anéis de energia.
- Usar lucide-react para ícones.
- Código modular com componentes reutilizáveis.
- Layout 16:9 otimizado para desktop.
- Aparência premium, glassmorphism, neon cyan, teal, violet, dark graphite.

O projeto deve conter package.json, index.html, src/main.jsx e src/styles.css.
